# Быстрые тексты — лендинг

Исходник публичного сайта: **https://andreevgeny.github.io/ux/**

Лендинг системного писателя Евгения Андреева: UX-микрокопирайт, техническая документация и регламенты, промпты и eval-контур для LLM. Статические HTML-страницы без сборки, деплой через GitHub Pages из ветки `main`.

## Локальный редактор

```
~/projects/ux/index.html          — лендинг
~/projects/ux/cases/index.html    — страница кейсов
```

После правок:

```
git add -A && git commit -m "..." && git push
```

GitHub Pages подхватит коммит за ~30 с.

## Структура репозитория

| файл | назначение |
|---|---|
| `index.html` | сам лендинг (тема, секции, скрипты) |
| `cases/index.html` | страница кейсов — два разбора «ТЗ → решение → почему» |
| `cases/case-1-cover.jpg` | обложка к статье в первом кейсе |
| `og-image.png` | 1200×630 — превью ссылки в Telegram и соцсетях |
| `favicon.png` | 256×256 — фавикон + apple-touch-icon |
| `404.html` | страница «не найдено» в стиле лендинга |
| `robots.txt` | разрешает всё + ссылка на sitemap |
| `sitemap.xml` | лендинг и страница кейсов |

## Технические решения

- **Тема.** Светлая + тёмная (переключатель в правом нижнем углу, состояние в `localStorage`, ключи `pf-theme` / `pf-metal`). Акцент: латунь → бронза → медь.
- **Шрифты.** Oswald, Golos Text, IBM Plex Mono — через Google Fonts.
- **OG/Twitter.** Полный набор: `og:title/description/image/url/locale`, `twitter:card=summary_large_image`, `canonical`.
- **JSON-LD.** `Person` с `knowsAbout`, `image`, `sameAs` (включая портфолио).
